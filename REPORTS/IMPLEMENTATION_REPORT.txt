1. ARCHITECTURE OVERVIEW
================================================================================

The backend `content` app is a complete Content Management System for an
educational platform (Blackboard/Classroom style). It provides full CRUD for
courses, chapters, and learning materials, plus 10 advanced functionalities.

Models (10 entities):
  - Course              : Course metadata (title, description, level, language,
                          status, content_type, markdown/latex content, owner,
                          scheduled_publish_at, estimated_reading_minutes, slug)
  - Chapter             : Course chapters with ordering
  - CourseMaterial      : Learning materials attached to course/chapter
  - AudioMaterial       : Audio-specific metadata (duration, language)
  - DocumentMaterial    : Document-specific metadata (page_count, mime_type)
  - VideoMaterial       : Video-specific metadata (duration, resolution, language)
  - Transcription       : Audio/PDF transcription text
  - Summary             : Content summary
  - CoursePresence      : Real-time WebSocket presence tracking
  - CourseVersion       : Immutable snapshots for versioning/rollback
  - CoursePrerequisite  : Prerequisite relationships with cycle detection

================================================================================
2. ENDPOINTS SUMMARY (/api/v1/content/)
================================================================================

CRUD ENDPOINTS:
  GET/POST    /courses/                          List/create courses
  GET/PUT/DELETE /courses/{id}/                  Course detail/modify/delete
  GET/POST    /chapters/                         Chapter CRUD (filter: course)
  GET/PUT/DELETE /chapters/{id}/                 Chapter detail
  GET/POST    /materials/                        Material CRUD (filters: course, chapter, material_type)
  GET/PUT/DELETE /materials/{id}/                Material detail
  GET         /materials/{id}/download/          Download material file
  GET/POST    /audio/                            AudioMaterial CRUD (filter: material)
  GET/PUT/DELETE /audio/{id}/                    Audio detail
  GET/POST    /documents/                        DocumentMaterial CRUD (filter: material)
  GET/PUT/DELETE /documents/{id}/                Document detail
  GET/POST    /videos/                           VideoMaterial CRUD (filter: material)
  GET/PUT/DELETE /videos/{id}/                   Video detail
  GET/POST    /transcriptions/                   Transcription CRUD (filter: material)
  GET/PUT/DELETE /transcriptions/{id}/           Transcription detail
  GET/POST    /summaries/                        Summary CRUD (filter: material)
  GET/PUT/DELETE /summaries/{id}/                Summary detail

ADVANCED ENDPOINTS (non-CRUD):
  POST   /courses/{id}/publish/                  Publish a draft course
  POST   /courses/{id}/archive/                  Archive a course
  GET    /courses/stats/                         Course statistics (draft/published/archived counts)
  POST   /courses/{id}/create_version/           Create version snapshot
  GET    /courses/{id}/versions/                 List version snapshots
  POST   /courses/{id}/rollback/                 Rollback to a previous version
  POST   /courses/{id}/duplicate/                Duplicate course (clone chapters + materials)
  GET    /courses/{id}/export/                   Export course as ZIP (metadata + files)
  POST   /courses/{id}/submit_for_review/        Submit draft for admin review
  POST   /courses/{id}/approve/                  Approve pending_review course (admin)
  POST   /courses/{id}/reject/                   Reject pending_review course to draft (admin)
  GET/POST /courses/{id}/prerequisites/          List/add prerequisites
  DELETE /courses/{id}/prerequisites/{prereq_id}/ Remove a prerequisite
  GET    /courses/{id}/presence/                 REST presence list
  POST   /materials/{id}/generate_thumbnail/     Generate thumbnail preview

WEBSOCKET ENDPOINT:
  WS /ws/content/courses/{course_id}/presence/   Real-time presence (join/leave/heartbeat)

================================================================================
3. PERMISSIONS MODEL
================================================================================

- Professor/Admin: Full CRUD on their own courses
- Student: Read-only access to published courses and their materials
- Admin: Can approve/reject pending_review courses
- Course owner required for: publish, archive, duplicate, export, create_version,
  rollback, submit_for_review, prerequisites add/remove
- Unauthorized access returns 403 Forbidden

4. 10 ADVANCED FUNCTIONALITIES IMPLEMENTED
================================================================================

#1 REAL-TIME PRESENCE (WebSocket)
  - Model: CoursePresence (course, user, channel_name, joined_at, last_seen)
  - Consumer: PresenceConsumer (channels.generic.websocket.AsyncWebsocketConsumer)
  - URL: /ws/content/courses/{course_id}/presence/
  - Messages: join, leave, heartbeat
  - REST endpoint: GET /courses/{id}/presence/
  - Tests: 4

#2 THUMBNAIL GENERATION (Pillow)
  - Field: CourseMaterial.thumbnail (ImageField)
  - Utility: content/thumbnail_utils.py (Pillow-based)
  - Supports: PDF first page (PyMuPDF), video frame (OpenCV), audio waveform,
              image resize, type placeholders (document/audio/video/code/etc.)
  - Endpoint: POST /materials/{id}/generate_thumbnail/
  - Tests: 3

#3 COURSE VERSIONING
  - Model: CourseVersion (course, version_number, snapshot JSON, change_description,
            created_by, created_at)
  - Class methods: create_snapshot(), apply_to()
  - Endpoints: POST create_version, GET versions, POST rollback
  - Auto-snapshot before rollback
  - Tests: 5

#4 SCHEDULED PUBLISHING
  - Field: Course.scheduled_publish_at (DateTimeField)
  - Auto-publish in Course.save() when scheduled time is in the past
  - Management command: python manage.py auto_publish
  - Tests: 3

#5 COURSE PREREQUISITES
  - Model: CoursePrerequisite (course, prerequisite_course, created_at)
  - Circular dependency detection (_would_create_cycle)
  - Self-reference prevention (CheckConstraint)
  - Endpoints: GET/POST prerequisites, DELETE remove_prerequisite
  - Tests: 5

#6 ESTIMATED READING TIME
  - Field: Course.estimated_reading_minutes (IntegerField)
  - Auto-calculated in Course.save() from description + markdown word count
  - ~200 words/minute, +1 min per audio/video material
  - Tests: 2

#7 DUPLICATE COURSE
  - Endpoint: POST /courses/{id}/duplicate/
  - Clones course + all chapters + all materials
  - Copies type-specific details (AudioMaterial, DocumentMaterial, VideoMaterial)
  - New course status: draft
  - Tests: 3

#8 EXPORT COURSE (ZIP)
  - Endpoint: GET /courses/{id}/export/
  - ZIP contains: course_metadata.json, chapters.json, materials.json, files/
  - FileResponse with attachment disposition
  - Tests: 3

#9 SLUG SEO-FRIENDLY
  - Field: Course.slug (SlugField, unique)
  - Auto-generated from title via django.utils.text.slugify
  - Uniqueness ensured with counter suffix (-1, -2, ...)
  - Tests: 3

#10 PENDING REVIEW MODERATION
  - Status: pending_review added to STATUS_CHOICES
  - Endpoints: POST submit_for_review (professor), POST approve (admin), POST reject (admin)
  - Workflow: draft -> pending_review -> published/draft
  - Tests: 5
